# Contributing

Thank you for wanting to help with Usuals.

## Issues are welcome

Bug reports, ideas and questions are all welcome as issues. A good bug report says:

- what you did, and what you expected to happen
- what happened instead, with a screenshot if it is about how something looks
- your Chrome version, and whether Google Calendar was in light or dark theme
- the language Google Calendar is shown in, if it is not English

## Pull requests are not accepted for now

Usuals is developed by one person, and for now every line of it is written by its author, so pull requests are closed without being merged. If you have a fix in mind, open an issue describing it instead. That is just as useful, and it may be picked up.

This may change later; if it does, this file will say how.
